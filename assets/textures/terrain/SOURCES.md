# Texturas de terreno

Este directorio contiene cuatro texturas tileables ligeras creadas específicamente para **Naranjal Survival**: `grass.svg`, `dirt.svg`, `mud.svg` y `rock.svg`.

## Criterio visual

Antes de integrarlas se revisaron varias bibliotecas CC0 adecuadas para videojuegos 3D:

- **Voxel Core Lab – Hand-Painted Seamless Terrain Textures**: pack CC0 de 16 texturas 1024×1024 de hierba, piedra, tierra y agua, pensado expresamente para Godot/Unity/Unreal.
- **OpenGameArt – CC0 Terrain Textures / Seamless Grass Texture II**: colecciones públicas de texturas de terreno repetibles.
- **ambientCG – Grass001, Ground048 y Rock027**: materiales PBR CC0 con variantes 1K y superiores.

Para esta primera versión se ha optado por un set propio de SVG procedurales en lugar de incorporar fotografías/PBR externas. Así se mantiene el aspecto stylized tipo *Raft*, el peso de la exportación Web es mínimo y el proyecto no depende de archivos ni atribuciones de terceros.

Las cuatro texturas de este directorio forman parte del propio proyecto y pueden modificarse libremente junto con el resto del código y assets de Naranjal Survival.
