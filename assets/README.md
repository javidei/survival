# Assets

En 0.1.0 el arte jugable se genera con primitivas y materiales de Godot desde `world_builder.gd`.

Carpetas futuras sugeridas:

- `assets/models/`: GLB/GLTF definitivos.
- `assets/materials/`: materiales y shaders.
- `assets/textures/`: texturas.
- `assets/audio/`: ambiente, pasos y SFX.
- `assets/ui/`: iconos e interfaces.

Mantener un estilo stylized/low-poly con siluetas claras y colores vivos, evitando depender de assets con licencias restrictivas.
